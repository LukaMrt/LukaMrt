### 🚀 Parraindex — mon projet perso

<p align="center">
  <a href="https://github.com/LukaMrt/Parraindex">
    <img src="https://stats-github.lukamaret.com/api/pin/?username=LukaMrt&repo=Parraindex&theme=default&hide_border=true&bg_color=00000000" alt="Parraindex" />
  </a>
</p>

Projet de 2ᵉ année à l'IUT, réalisé en équipe de 4 sur un sujet libre. On est partis d'un problème concret : les liens de parrainage entre étudiants s'accumulaient sans qu'aucun outil ne permette de les visualiser. Le rendu noté est terminé depuis longtemps ; je continue seul à le faire évoluer, parce qu'il est toujours utilisé aujourd'hui — API Symfony découplée d'une SPA React, avec une interface d'admin pour la validation des demandes et l'import de données.
